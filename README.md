# フォーム解析ツール

ブラウザだけで動く動作解析ページです。動画は外部に送信されず、解析はすべて端末内で行われます。
パソコンなら HTML をそのまま開いても使えます。
**iPhone/iPad で使う場合は URL で開く形にしてください**(`file://` だと Safari が解析ライブラリを読み込めません)。
無料での公開手順は [DEPLOY.md](./DEPLOY.md) を参照してください。

公開して一度開いておくと、Service Worker が解析ライブラリとモデルを保存するため、
**電波の弱い場所でもオフラインで動きます**。Safari の「ホーム画面に追加」でアプリのように使えます。

| ファイル | 用途 |
|---|---|
| `index.html` | 入口ページ |
| `formanalyzer.html` | 投球・打撃フォーム解析(本体) |
| `pitching-analyzer.html` | 投球動作解析 Ver.1(設計仕様書に沿った投球専用版) |
| `batting-analyzer.html` | 打撃動作解析 Ver.1A(設計仕様書に沿った打撃専用版) |
| `sw.js` / `manifest.webmanifest` / `icon-*.png` | オフライン動作とホーム画面追加のため |

## Ver.1 専用版(pitching-analyzer / batting-analyzer)

`formanalyzer.html` とは別に、詳細測定仕様書に沿って作り直した専用版があります。
選手ごとの較正、イベントの手動確定、測定信頼度、本人比、アラート、CSV/JSON 出入力まで入っています。

- 仕様: [`docs/pitching-v1-measurement-spec.md`](../docs/pitching-v1-measurement-spec.md) /
  [`docs/batting-v1a-measurement-spec.md`](../docs/batting-v1a-measurement-spec.md)
- **距離の基準が投球版と打撃版で違います。** 投球は「足首〜鼻 ÷ 0.89」、
  打撃は「胴体長 ÷ 0.288」です。打者は構えからフォローまで一度も直立せず、
  沈み込みで足首〜鼻が10%以上縮むためです。**両者の身長比の絶対値は直接比べられません。**
- **60fps 以上(できれば iPhone のスローモーション 120/240fps)で撮ってください。**
  30fps だとタイミング系の分解能が足りず、比較・アラートを自動的に止めます。
- 比較は**本人の直近スイング/投球との差**だけです。他人や一般的な目安とは比べません。
- アラートのしきい値は外部から与えた初期値です。10〜30本たまった時点で、
  「再現性」タブに出る**本人の SD** を見て「設定」タブで調整してください。
- iOS Safari はしばらく開かないと保存データを消すことがあります。
  練習後に**JSON を書き出して手元に残す**運用を前提にしています。

ヘッダーのセレクタで**投球 / 打撃**を切り替えます。チェックポイントの定義ごと変わるため、
切り替えると記録済みのチェックポイントは破棄されます(軌跡のON/OFFは動作ごとに保存されます)。

## 共通機能

- 0.1秒 / 0.01秒 / 1フレーム のコマ送り(タップ・長押し連続送り・キーボード)
- トリミング(解析範囲の切り出し)、範囲のリピート再生
- 骨格・関節軌跡の重ね描き
- チェックポイントの自動検出と手動記録、CSV書き出し
- 時系列グラフ(タップでその時刻へ移動)
- 2動画の並列比較(トリミング開始点で同期、時間伸縮あり)
- 再現性の確認(複数の試技を保存し、骨格のゴースト重ね表示とばらつきの数値化)
- 撮影アングルの切り替え(側面 / 正面)、2D・3D計測、鏡像動画への対応

## 投球と打撃の違い

|  | 投球 | 打撃 |
|---|---|---|
| チェックポイント | 始動 / 上げ足最高点 / 接地 / リリース / フォロー | 構え / トップ / ステップ接地 / インパクト / フォロー |
| 側面の計測 | 肘・肩・股関節・膝の角度 | 前後の膝/肘、前股関節、体幹の前傾、ステップ幅、手の高さ |
| 正面の計測 | 肩/骨盤ライン傾き、体幹の側方傾斜、アームスロット、開き差、頭・踏み出し足の位置 | 肩/骨盤ライン傾き、体幹の左右傾き、開き差、頭の左右・高さ、踏み込みの左右 |
| 目安値 | 肘・肩・膝・体幹側方傾斜(ASMI/AOSSM等の投球研究に基づく) | なし(確立された基準値が乏しいため、比較で見る前提) |
| 左右の指定 | 投球腕 | 打席(右打ち/左打ち) |

## 再現性の見かた

同じ動作を何度か撮って「再現性」タブに試技として保存すると、次が分かります。

- **ゴースト** — チェックポイント付近へ移動すると、他の試技の骨格が色分けで重なります。
  腰の中心を原点、胴体長を1として正規化してから重ねるので、撮影距離や立ち位置が違っても形だけを比べられます。
- **姿勢のばらつき** — 各試技の骨格が平均の形からどれだけ離れているか(胴体長=1)。小さいほど毎回同じ形。
- **±SD** — 各計測項目の標準偏差。
- **テンポ** — 場面と場面の間隔のばらつき。動作の速さの再現性。

試技はブラウザに保存され、次回も残ります。動作(投球/打撃)ごとに別管理です。
数値の絶対値より、**練習の前後で小さくなっているか**を見てください。

## 投球動作解析 Ver.1 (pitching-analyzer.html)

`docs/pitching-v1-measurement-spec.md` の仕様に沿って作り直している投球専用版です。

**Phase 4 まで実装済み**: 選手管理(身長・投球腕)、較正(既知長2点から k_nose を実測)、
セッション管理(IndexedDB)、トリミング、範囲の事前解析と平滑化、
コマ送り(実フレーム時刻基準)と0.001秒送り、
イベント6点(セット/最大脚上げ/接地/トップ/リリース/フィニッシュ)の候補検出と、
前後±5コマのサムネイルによる手動確定、
指標の算出(ストライド長・骨盤中心の移動・前膝角度と伸展量・肘角度・体幹前傾・
タイミング・リリース高さ/前後位置)と検出信頼度、球速の手入力、球の記録、
運動連鎖(近似)の重ね描画と前膝の使い方。

**未実装**: 複数球の平均・SD・本人比、疲労解析、アラート、ドリル、CSV出力。
Phase 4 以降で追加します。

## 注意

- 単眼動画からの推定です。奥行き方向の動き(回旋など)は原理的に精度が落ちます。
  数値は**同一カメラ・同一アングルでの比較**に使うのが最も有効です。
- スイングや投球は速いため、**30fpsではインパクト/リリース前後がほとんど残りません**。
  可能なら60fps以上(120/240fpsが理想)で撮影してください。
- 再現性の数値にはチェックポイントの位置ズレも混ざります。自動検出のまま比べると
  フォームではなく検出位置の差を見てしまうことがあるため、各場面をコマ送りで揃えてから記録し直してください。
- 打撃版はバット自体を検出しません。代わりに両手の中点の軌跡を「手の軌道」として表示します。
